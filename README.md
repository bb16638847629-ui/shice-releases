# 时策

时策是原生 macOS 桌面策略工具。本仓库用于发布经过审核的安装包、版本更新信息和使用说明，不提供数据库、账号、个人配置或用户草稿。

## 支持环境

当前目标为 Apple 芯片 Mac，macOS 14 或更新版本。Windows 和 Intel Mac 尚未验收。

## 发布状态

1.0.8 在线更新与规则交接功能正在验证。本仓库尚不提供已通过验收的1.0.8下载；请勿将测试版本作为正式发布。

现有1.0.7没有在线更新模块，需要手动安装首次包含该模块的版本。后续更新由用户确认，升级前暂存本地草稿并保留恢复备份；暂存不等于提交数据库。

## 安装与使用

仅使用 Releases 中明确列为可用的版本，核对支持平台、发布说明和校验值。应用签名、公证及企业设备准入状态以对应版本说明为准，不要求关闭系统安全设置。

请勿在公开 Issue、评论或附件中提交数据库地址、账号、密码、业务明细或草稿。业务资源是否包含于安装包，以该版本发布说明为准。

第三方组件许可证随相应安装包提供。
